## Install

1. Copy `README.md` and `assets/` into the root of `MaiCoderHoon/MaiCoderHoon`.
2. Replace `.github/scripts/gen_stats.py` with this bundled version.
3. Keep `.github/workflows/snake.yml` and `.github/workflows/stats.yml` unchanged.
4. Commit and push to `main`. Existing workflows continue to generate the contribution snake and refresh `assets/stats.svg`.

The redesign removes unverified performance percentages and experience-duration claims. Existing project/contact links, toolkit, certification labels and dynamic integrations are retained.
